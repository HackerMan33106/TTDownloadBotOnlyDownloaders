# 🎬 TTDownloadBot - Only Downloaders

Современный и высокопроизводительный Telegram-бот для скачивания медиаконтента (видео, слайдшоу, аудио, фото) из TikTok, YouTube, Instagram и более чем 10 других платформ с поддержкой файлов до **2 GB**.

---

## ✨ Основные возможности

### 📹 Скачивание и обработка медиа
- 🎥 **Видео высокого качества** — TikTok, YouTube, Instagram Reels, Twitter/X, Reddit, VK, Rutube, Dzen, PornHub и др.
- 📸 **Слайдшоу TikTok** — автоматическая нарезка фото-каруселей на медиа-группы (до 10 фото в сообщении) с сохранением оригинального аудио.
- 🎵 **Скачивание только аудио (`-a` / `-ф`)** — мгновенное извлечение и отправка MP3-дорожки. Музыкальные сервисы (SoundCloud) автоматически распознаются как аудио.
- ⚡ **Мгновенная доставка аудио** — при запросе только аудио файл отдаётся пользователю сразу после нарезки (~10–12 секунд), а архивация в мусорную группу выполняется в фоне.
- 🔗 **Множественная загрузка** — поддержка отправки нескольких ссылок в одном сообщении (параллельная обработка).
- ✂️ **Автоматический сплиттер видео** — если файл превышает лимит отправки, он автоматически делится на части без потери качества.
- 🧽 **Умная нормализация ссылок** — разворачивание коротких ссылок (`vt.tiktok.com`, `youtu.be`) и очистка от трекинговых параметров (`utm_source`, `si=`, `igsh=`).

### ⚡ Кэширование и синхронизация (In-Flight Deduplication)
- 📦 **Облачное хранилище Telegram (`TRASH_GROUP_ID`)** — загруженные файлы кэшируются в закрытом канале/группе Telegram, что позволяет отдавать их повторно за доли секунды по `file_id` без повторной нагрузки на диск и сеть.
- 🔒 **Дедупликация одновременных запросов (In-Flight Lock)** — если несколько пользователей одновременно отправляют одну и ту же ссылку, скачивание выполняется только **один раз**. Остальные запросы безопасно ожидают завершения и получают готовый файл из кэша. Исключены дубликаты в базе данных и хранилище.

### 🛡️ Безопасность и контроль доступа
- 👥 **Белый список (Whitelist)** — разграничение доступа для пользователей и групповых чатов (`/wl`).
- 📊 **Суточные лимиты и блокировка (`/bl`)** — настраиваемое количество скачиваний в день со сбросом в полночь UTC+1. Получение файлов из кэша лимит не расходует.
- 🗑️ **Безопасные кнопки управления** — удаление сообщений защищено криптографической HMAC-подписью: удалить сообщение может только его владелец или администратор.
- 🛡️ **Защита от SSRF** — блокировка запросов к внутренним и приватным сетевым адресам.

### 📊 Мониторинг и отладка
- 📈 **Статистика диска (`/storage`)** — отображение свободного места, размера базы данных SQLite, временных файлов и кэша.
- 🏓 **Проверка задержки (`/ping`)** — измерение времени отклика Telegram API с цветовой индикацией.

## 🔧 Команды бота

### Для всех пользователей
- `/start` — приветствие и главное меню.
- `/help` — список доступных команд и справка.
- `/ping` — проверка отклика и задержки бота.
- `/dw <url>` — скачать медиа по ссылке с любой поддерживаемой платформы.
- `/dw -a <url>` — скачать только аудио (MP3) из ссылки (также поддерживается русская раскладка: `/dw -ф <url>`).

> **Совет:** Для TikTok можно просто отправить ссылку в чат (без команды `/dw`). Для получения только аудио добавьте в конце сообщения флаг `-a` или `-ф`.

### Для администраторов
- `/wl` — управление белым списком пользователей и групп (`/wl -a <id>`, `/wl -r <id>`).
- `/bl` — управление суточными лимитами и чёрным списком (`/bl -a <id> <кол-во>`, `/bl -r <id>`).
- `/admin` — управление списком администраторов (`/admin -a <id>`, `/admin -r <id>`).
- `/storage` — статистика занятого дискового пространства и состояния кэша.

## ⚙️ Конфигурация (`.env`)

Создайте файл `.env` в корневой директории проекта на основе следующего примера:

```env
# Токен бота Telegram (получить у @BotFather)
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# ID постоянного администратора (числовой Telegram ID)
PERMANENT_ADMIN=123456789

# Telegram ID закрытой группы/канала для облачного кэша файлов (число, например -100...)
TRASH_GROUP_ID=-1001234567890

# Начальные белые списки (ID через запятую)
WHITELIST_USERS=123456789
WHITELIST_GROUPS=-1009876543210

# Настройки локального Telegram Bot API (позволяет отправлять файлы до 2000 MB)
USE_LOCAL_API=true
LOCAL_API_URL=http://telegram-bot-api:8081
TELEGRAM_API_ID=1234567
TELEGRAM_API_HASH=0123456789abcdef0123456789abcdef

# Spotify API (опционально для треков Spotify)
SPOTIFY_CLIENT_ID=
SPOTIFY_CLIENT_SECRET=
SPOTIFY_REFRESH_TOKEN=

# Режим отладки (true/false) — динамически подхватывается на лету при изменении файла
DEBUG_MODE=false

# Директория для данных бота внутри контейнера
DATA_DIR=/app/data
```

## 🐳 Быстрый запуск (Docker Compose)

Проект оптимизирован для работы в Docker с локальным сервером **Telegram Bot API**:

1. **Клонируйте репозиторий:**
   ```bash
   git clone <url_репозитория>
   cd TTDownloadBot
   ```

2. **Создайте и заполните `.env`:**
   ```bash
   cp .env.example .env
   nano .env
   ```

3. **(Опционально) Добавьте cookies:**
   Если требуется обход ограничений возраста или авторизация для YouTube/TikTok, поместите файл `cookies.txt` (в формате Netscape HTTP Cookie File) в папку `./data/cookies.txt`.
   > **Примечание:** Экспортировать cookies в формате Netscape можно с помощью браузерных расширений (например, *Get cookies.txt LOCALLY*).

4. **Запустите проект:**
   ```bash
   docker compose up -d --build
   ```

5. **Просмотр логов:**
   ```bash
   docker compose logs -f bot
   ```

```
│   ├── whitelist.py     # Белые списки пользователей и групп

│   └── audio.py         # Хранилище метаданных аудио
├── handlers/            # Обработчики Aiogram
│   ├── commands/        # Команды бота (/dw, /wl, /bl, /storage, /admin)
│   ├── messages.py      # Обработчик прямых ссылок TikTok

│   ├── crypto.py        # HMAC-подпись callback-запросов
│   ├── tiktok.py        # Парсинг и нормализация TikTok URL
│   └── helpers.py       # Вспомогательные функции и кнопки
├── docker-compose.yml   # Запуск бота и локального Telegram Bot API
├── Dockerfile           # Multi-stage сборка (Python 3.11 + ffmpeg + Deno)
└── requirements.txt     # Зависимости Python
```
